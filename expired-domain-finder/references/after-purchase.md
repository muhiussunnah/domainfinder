# After buying an expired domain

The goal is to keep the trust the domain already has and turn it into a genuinely useful site on the same topic.

## First week

1. **DNS and hosting** live within a day, HTTPS on, one canonical host (with or without `www`).
2. **Rebuild what earned the links.** Pull the domain's most-linked URLs (DataForSEO `backlinks/domain_pages`, or the Wayback list of archived pages). For each URL with backlinks, publish a new, better page on the same topic at the same path, or 301 it to the closest new page. Do not copy old content: rewrite it.
3. **Bing Webmaster Tools**: add and verify the site, submit the sitemap, and use the URL submission / IndexNow API for the rebuilt URLs. Bing still knowing the domain is why it was chosen; this is where it pays off.
4. **Google Search Console**: verify, submit the sitemap, check Manual Actions and Security Issues on day one.
5. **Homepage** that states clearly who runs the site and what it covers. New owner, same topic.

## First three months

- Publish steadily on the niche (product guides, comparisons, how-tos). Keep the topic consistent with the domain's past.
- Add Amazon Associates links only after there is real content. Follow the Operating Agreement: disclosure on every page with links, no prices copied without the API, no "amazon" in the domain.
- Watch Bing and Google impressions weekly. A domain that was clean usually shows Bing impressions within weeks.

## Do not

- Host unrelated or thin content to ride the old authority: Google's spam policies call this "expired domain abuse" and demote it.
- 301 a whole expired domain to a money site the day you buy it.
- Build a network of expired domains linking to each other.
- Buy links to "re-activate" the domain.
